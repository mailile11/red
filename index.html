How to play

The host starts each round. The doll switches between green and red at unpredictable intervals. Reach the finish line without moving during red light. Move during red and you're eliminated for that round.

This is a browser-to-browser peer connection using PeerJS for connection setup. It does not require a dedicated game server, but room setup needs internet access; gameplay data is sent directly between players.

Tip: For best results, open this page in a modern browser and allow it to stay in the foreground.
